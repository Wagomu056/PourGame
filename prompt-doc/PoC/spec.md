# ゲームタイトル： Pour Beer!

## 1. ゲーム概要

プレイヤーはビールの瓶詰めラインの作業員となり、左右に動くホースを操作して不安定な勢いで出るビールを瓶に注ぎ、王冠をセットして圧着する一連の作業を行います。制限時間内、または規定の本数を正確に完成させることを目指す、カジュアルなタイミング・アクション2Dゲームです。

---

## 2. 画面構成・UI

* **メインエリア**：ビール瓶が配置される場所、および上部に左右に移動可能な注ぎ口（ホース）が配置されます。
* **ホースの定位置（ホルダー）**：画面内の特定の位置に、初期状態のホースが置かれています。
* **完成カウント（画面右下）**：現在までに完成したビンの数が表示されます（初期値：0）。
* **ビールのインジケーター（演出）**：ホースの先から出るビールの「勢い（水流の太さや角度のブレ）」が視覚的に変化します。

---

## 3. ゲームフロー＆詳細仕様（ステップ別）

### ステップ 1：ビンの配置（自動）

* ゲーム開始時、または前のビンが完成して搬出された後、自動的に新しい空のビンが画面左側に配置されます。

### ステップ 2：ホースの取得

* プレイヤーが定位置にあるホースを「マウス左クリック」すると、ホースを掴んだ状態（ホールド状態）になります。

### ステップ 3：ビールの出始め

* ホースを定位置から引き離した（掴んだ）瞬間から、ホースの先端より自動的にビールが流れ出し始めます。

### ステップ 4：ビールの注入とコントロール

* **操作方法**：プレイヤーがマウスを左右に動かすと、ホースも連動して左右に移動します。
* **難易度要素（ビールの勢い）**：
* ビールが出る勢い（強さ、または左右へのわずかな飛び散り・軌道の変化）は**一定ではなく、ランダムまたは周期的に変動**します。
* プレイヤーは、ビールの流れる向きや勢いを視覚的に判断し、ビンの口に的確にビールが入るよう、ホースの左右位置を微調整し続ける必要があります。
* *（仕様補足：ビンの口から外れてビールがこぼれた場合、ビンのゲージは溜まりません。）*

### ステップ 5：満杯とホースの返却

* ビールがビンの容量上限（満杯）に達したことを検知すると、画面に「満杯！」などの目印（エフェクトやSE）が表示されます。
* プレイヤーはホースを「元の定位置（ホルダー）」までマウスで移動させ、クリックを離す（または自動で吸着する）ことで戻します。ホースが定位置に戻ると、ビールの流出が停止します。

### ステップ 6：王冠の配置

* プレイヤーがキーボードの「W」キーを押すと、ビンの真上に王冠がセットされます。

### ステップ 7：王冠の圧着

* プレイヤーがキーボードの「Space（スペース）」キーを押すと、圧着機（キャッパー）が作動し、王冠がビンにしっかりと固定されます（圧着完了のSEとアニメーション）。

### ステップ 8：ビンの完成とカウント

* 圧着が完了すると、そのビンは「完成品」となり、自動的に画面右側へ搬出されます。
* 同時に、画面右下の「ビンのカウント」が「+1」されます。
* その後、自動的に「ステップ 1」に戻り、次の空のビンが左側から運ばれてきます。
